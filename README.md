# OIBSIP Internship Tasks

This repository contains all tasks completed as part of the Oasis Infobyte Internship.

📂 Tasks

 Task 1: Voice Assistant
 
File Name: assistant.py

Description:A Python-based voice assistant that takes voice commands and responds using text-to-speech. It can perform basic tasks and interact with the user.

 Task 2: BMI Calculator

File Name: bmi.py

Description:A command-line Python application that calculates Body Mass Index (BMI) using user input. It categorizes BMI into health ranges and provides suggestions based on the result.
